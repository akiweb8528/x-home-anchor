# X ホームの閲覧位置

X公式のホームタイムラインで、新着を表示した後も読んでいた投稿の位置を保つChrome拡張です。投稿のリポストボタンを長押しして、その投稿の引用一覧を開くこともできます。

個人開発の非公式ツールで、X社とは無関係です。[MIT License](LICENSE)で提供します。

この拡張は、AkiWeb Hakoniwaが自分で使いたい機能をもとに、AIを活用して開発しました。作者自身が使いながら調整していますが、実装の細部すべてを把握しているわけではありません。

位置保持とカウンターの対象は `https://x.com/home` の「おすすめ／フォロー中」（日本語・英語表示）とカスタムタイムラインです。リポストボタンの長押しは、ホームのタブ認識に依存せず `https://x.com/*` の投稿で動作します。実行時の外部依存・サーバーはありません。取得件数や取得頻度を増やす機能、自動更新、投稿取得のための自動スクロールはなく、公式の通知・投稿・返信・DMの送受信処理には手を加えません。

## 導入・更新

### ZIPから導入・更新する

1. [v0.2.7の配布ZIPをダウンロード](https://github.com/akiweb8528/x-home-anchor/raw/refs/heads/main/release/x-home-anchor-v0.2.7.zip)し、Chromeから選べる専用フォルダーへ展開します。通常の利用にはGit・Node.js・npm・サーバーの起動は不要です。
2. Chrome 120以上で `chrome://extensions` を開き、「デベロッパーモード」をONにします。
3. 「パッケージ化されていない拡張機能を読み込む」で、展開した **`manifest.json` が直接入っているフォルダー**を選びます。導入先のフォルダーは利用中も保持してください。
4. 既に開いていたXのタブを再読み込みします。位置保持は常時有効で、ピン留めした拡張のポップアップから状態を確認できます。

更新時は、導入先の同じフォルダーの中身を新しいZIPの内容で置き換え、Chromeの拡張管理画面で拡張を「再読み込み」します。その後、Xのタブも再読み込みしてください。拡張だけを再読み込みしても、既に開いたページの処理は更新されません。

### ソースからビルドする

Git、Node.js 22.18以上（検証は24系）、npm、Chrome 120以上を使います。

```sh
git clone https://github.com/akiweb8528/x-home-anchor.git
cd x-home-anchor
npm ci
npm run build
```

1. Chromeで `chrome://extensions` を開き、「デベロッパーモード」をONにします。
2. 「パッケージ化されていない拡張機能を読み込む」で、このリポジトリの **`dist` フォルダー**を選びます。
3. 既に開いていたXのタブを再読み込みします。位置保持は `https://x.com/home` で確認できます。

Windows版ChromeとWSLなど、ビルドとChromeの環境が異なる場合は、`dist` の中身をChromeから選べる専用フォルダーへコピーし、そちらを読み込みます。導入先のフォルダーは利用中も保持してください。通常の利用にはNode.jsやサーバーの起動は不要です。

更新は取得したリポジトリで行います。

```sh
git pull --ff-only
npm ci
npm run build
```

コピー先を読み込んでいる場合は、その中身も新しい `dist` で置き換えます。その後、ZIPからの更新と同様に拡張とXのタブを再読み込みしてください。

## 使い方

**引用一覧を開く：** 投稿のリポストボタンをマウス左ボタンまたはタッチで0.6秒押し続けると、離す前に同じタブでその投稿の引用一覧へ移動します。リポスト済みのボタンも対象です。ホームとポスト詳細画面に対応します。通常はX自身の「ポストアクティビティを表示」リンクを使ってSPA遷移します。メニューボタンがない場合や、最大1秒待っても移動できない場合は、従来のURL遷移（ページ再読み込み）へ切り替えます。操作の中断や対象投稿の消失・差し替え時には切り替えません。短くクリック／タップすると、待ち時間を加えず従来のリポストメニューが開きます。右クリック・中クリック・キーボードによる通常操作も維持します。

0.6秒未満で離す、押し始めから10pxを超えて動かす、ボタンから外れる、スクロールする場合は長押しを取り消します。対象投稿の消失・差し替え、画面移動、タブの非表示などでも取り消します。長押し成立後も、メニューや移動を待っている間のスクロール、ウィンドウのフォーカス喪失、ポインター操作の強制中断では遷移を取り消します。通常の指離しや要素間のフォーカス移動では取り消しません。投稿を確実に識別できない場合は引用一覧へ移動せず、通常操作を残します。引用カード内の投稿を外側の投稿として扱うことはありません。

**位置保持：** ホームの「おすすめ」「フォロー中」とカスタムタイムラインで、通常どおり閲覧し、Xの新着表示ボタンを操作します。取得中は表示中のタイムラインを一時的なコピーで固定し、その裏で位置を復元してから表示を戻します。ページ内部のスクロール自体を止める方式ではありません。取得前の先頭ポストの直前に新着ポストを確認できた場合は、その新着ポストの先頭を固定ヘッダーの下に揃えます。画面より背の高い投稿でも、先頭から読み始められる位置にします。対象を識別できない場合は従来の位置復元を使います。同じ投稿や記録した近傍投稿で復元し、正確に戻せなければ、追加領域の高さ、ページ全体の高さの増加量、表示件数の順に使い、読んでいた辺りへ一度だけ概算で移動します。ページ全体の高さにも仮想化による推定が含まれるため、投稿IDが戻ればその位置で補正します。新着の反映をDOMから確認できない場合も、操作から3秒待った後、表示件数と代表高さがあれば下へ進みます。新着表示後に下へ進めることを重視するため、概算にはずれがあり、同じ投稿やピクセル位置の一致は保証しません。同じ追加分を正確に復元できた後には概算を重ねません。先頭への巻き戻りを戻した後でも、新着の追加が続いた場合は補正を続けます。概算で現在位置より上へ戻すこともありません。概算後も元の投稿IDが再び描画されれば、操作から最大5秒の期限内で正確な位置へ補正します。大きな概算移動は一度だけです。Homeリンクによる更新には対応していません。

ホイール・タッチ・スクロールキー・スクロールバー等の本人の操作、明示的な移動を優先して補正と固定表示を中断します。ウィンドウのサイズ変更でも解除します。固定表示中はTabなどのキー入力でも解除します。固定表示中に投稿部分を押した場合は、裏側の別の投稿を誤操作しないよう、その操作では固定表示の解除だけを行います。続く通常のクリックはそのまま動きます。新着反映を確認できた場合は650msの猶予後も正確に戻せなければ概算し、補正は操作から最大5秒で終了します。必要な領域が一時的に消えた場合も、その期限内で復帰を待ちます。通常閲覧中の高さ変化等への補正は最大1.8秒で終了します。画面移動・タイムライン切替でも補正を終了します。ページ全体の再読み込み後の位置を永続的に復元する機能はありません。

一部または全ての投稿IDが取れない場合も、タイムライン領域を認識できていれば位置保持を続けます。ポップアップでは、位置保持の動作中・対象外・画面構造の認識不可・接続不可を確認できます。ポップアップを開かなくても位置保持とカウンターは動作します。

**左上のカウンター：** 操作した新着表示ボタンの表示件数を累計します。35件、70件と操作すると105になります。通常のキーボード操作による作動も対象で、件数のないボタン、表示の変化だけ、Homeリンクでは加算しません。新着の反映や補正の成否とは独立した値で、通信の取得件数・ユニーク投稿数・読了件数ではありません。

累計はページごとに0から始まり、再読み込み・新しいタブやウィンドウでは0に戻ります。同じページ内のタイムライン切替では保持します。ホーム以外では隠れ、同じページ内でホームへ戻ると再表示します。

位置保持にはON/OFF設定がなく、以前の版でOFFを保存していた場合も常時動作します。拡張全体を停止するには `chrome://extensions` でOFFにし、開いているXタブを再読み込みしてください。

## 権限とデータ取扱い

追加のAPI呼び出しや権限は不要です。content scriptは `https://x.com/*` 上のDOMを読み書きでき、位置保持とカウンターはホーム、長押しは投稿に紐づくリポストボタンを対象とします。引用一覧のURLもDOMから解決します。設定保存、Cookie・認証情報へのアクセス、通信の傍受・書換え、APIの再実行は行いません。外部へのデータ送信やテレメトリーはありません。

| データ | 保存先・上限・破棄条件 |
| --- | --- |
| 新着表示件数の累計 | ページのメモリーのみ。閉じる／再読み込みで破棄。タブ間共有・設定保存なし |
| 位置保持用ID・相対位置 | タブのメモリーに最大7件。新着処理は最大5秒。入力・画面切替・終了で破棄 |
| 概算用の計測値 | 最大500件の外側要素参照・座標・既知IDの並びと代表高さ・表示件数を最大5秒保持。新着判定用の取得前ID集合も最大500件。終了・中断で破棄 |
| 取得中の固定表示 | 表示中のタイムラインDOMの一時コピー。本文・画像要素を含み、動画・canvasは可能ならその時点の描画をコピー。補正終了・中断で破棄し、保存・外部送信はしない |
| DOM計測 | 最大500投稿要素。超過時は補正を休止し、部分的な計測値で補正しない |
| 長押しの対象・URL・ポインター位置 | ページのメモリーのみ。長押しの取り消し・対応するクリックの抑止終了・処理終了で破棄 |

本文・画像をファイルやストレージへ保存する処理はありません。固定表示のDOMコピーと位置保持のID記録はページ内の一時状態です。長押しの対象URLには投稿者名が含まれますが、永続保存しません。

## 確認範囲と制約

- v0.2.7の統合ビルドでは、型検査・95件のテストと、合成ページを使ったChromeの自動検証38ケースが通っています。実際のXでは、ホームとポスト詳細からの長押しが再読み込みなしで引用一覧へ移動すること、ホームで短くクリックすると通常のリポストメニューが開くことを確認しました。待機中の中断は合成DOM・合成ページで検証し、タッチ操作はChromeのエミュレーションです。統合後の実Xでの新着取得と実機タッチ操作は未確認です。[統合版の検証記録](verification/0.2.7.json) に条件と未確認範囲を記載しています。
- 位置保持の個別ビルドはWindows版Chrome 155のログイン済みXホームのカスタムタイムライン「AI」「ソフトウェア」で、35件の新着表示操作を確認しました。最終ビルドは「ソフトウェア」で検証しています。取得中の固定表示を確認し、既存ポストの直前の新着ポストの先頭が固定ヘッダーの下に揃うことを確認しています。自動検証には、同名のカスタムタブ、背の高い新着ポスト、新着1件で不要な概算を重ねないケースも含みます。[検証記録](verification/refresh-viewport.json) に範囲を記載しています。
- 長押しの個別ビルドは、合成DOM・合成ページの自動テストと、ログイン済みChromeの実際のXで確認しました。実Xの記録は、ホームからのSPA遷移と、詳細画面でメニューボタンの識別子を変えた通常遷移への切り替えです。検証条件・結果は [検証記録](verification/repost-quotes-spa.json) を参照してください。実機タッチ操作は未確認です。

XのDOM・文言・仮想化方式が変わると動作しなくなる場合があります。ページ全体とは別の内部スクロール領域には未対応です。補正は操作から最大5秒で終了し、通常終了時には描画を整えるため2フレーム待って固定表示を解除します。元の投稿が再び描画されない場合は概算位置になり、解除時のずれを完全には防げません。未読込のメディアやページ側が繰り返し移動する場合にも表示の差が残ることがあります。継続的な保守・サポートは保証しません。
