# X ホームの閲覧位置

X公式のホームタイムラインで、新着を表示した後も読んでいた投稿の位置を保つChrome拡張です。個人開発の非公式ツールで、X社とは無関係です。[MIT License](LICENSE)で提供します。

この拡張は、AkiWeb Hakoniwaが自分で使いたい機能をもとに、AIを活用して開発しました。作者自身が使いながら調整していますが、実装の細部すべてを把握しているわけではありません。

対象は `https://x.com/home` の「おすすめ／フォロー中」（日本語・英語表示）です。実行時の外部依存・サーバーはありません。取得件数や取得頻度を増やす機能、自動更新、投稿取得のための自動スクロールはなく、公式の通知・投稿・返信・DMの送受信処理には手を加えません。

## 導入・更新

Git、Node.js 22.18以上（検証は24系）、npm、Chrome 120以上を使います。

```sh
git clone https://github.com/akiweb8528/x-home-anchor.git
cd x-home-anchor
npm ci
npm run build
```

1. Chromeで `chrome://extensions` を開き、「デベロッパーモード」をONにします。
2. 「パッケージ化されていない拡張機能を読み込む」で、このリポジトリの **`dist` フォルダー**を選びます。
3. 既に開いていたXのタブを再読み込みし、`https://x.com/home` を開きます。
4. 拡張をピン留めしてポップアップを開き、状態を確認します。位置保持は常時有効です。

Windows版ChromeとWSLなど、ビルドとChromeの環境が異なる場合は、`dist` の中身をChromeから選べる専用フォルダーへコピーし、そちらを読み込みます。導入先のフォルダーは利用中も保持してください。通常の利用にはNode.jsやサーバーの起動は不要です。

更新は取得したリポジトリで行います。

```sh
git pull --ff-only
npm ci
npm run build
```

コピー先を読み込んでいる場合は、その中身も新しい `dist` で置き換えます。その後、Chromeの拡張管理画面で拡張を「再読み込み」し、Xのタブも再読み込みしてください。拡張だけを再読み込みしても、既に開いたページの処理は更新されません。

## 使い方

**位置保持：** 通常どおり閲覧し、Xの新着表示ボタンを操作します。同じ投稿や記録した近傍投稿で復元し、正確に戻せなければ、追加領域の高さや表示件数から読んでいた辺りへ一度だけ概算で移動します。新着の反映をDOMから確認できない場合も、操作から3秒待った後、表示件数と代表高さがあれば下へ進みます。新着表示後に下へ進めることを重視するため、概算にはずれがあり、同じ投稿やピクセル位置の一致は保証しません。同じ追加分を正確に復元できた後には概算を重ねません。先頭への巻き戻りを戻した後でも、新着の追加が続いた場合は補正を続けます。概算で現在位置より上へ戻すこともありません。Homeリンクによる更新と、概算後のID復帰に合わせた再補正には対応していません。

ホイール・タッチ・スクロールキー・スクロールバー等の本人の操作、明示的な移動を優先して補正を中断します。新着反映を確認できた場合は650msの猶予後も正確に戻せなければ概算し、補正は操作から最大5秒で終了します。必要な領域が一時的に消えた場合も、その期限内で復帰を待ちます。通常閲覧中の高さ変化等への補正は最大1.8秒で終了します。画面移動・タイムライン切替でも補正を終了します。ページ全体の再読み込み後の位置を永続的に復元する機能はありません。

一部または全ての投稿IDが取れない場合も、タイムライン領域を認識できていれば位置保持を続けます。ポップアップでは、位置保持の動作中・対象外・画面構造の認識不可・接続不可を確認できます。ポップアップを開かなくても位置保持とカウンターは動作します。

**左上のカウンター：** 操作した新着表示ボタンの表示件数を累計します。35件、70件と操作すると105になります。通常のキーボード操作による作動も対象で、件数のないボタン、表示の変化だけ、Homeリンクでは加算しません。新着の反映や補正の成否とは独立した値で、通信の取得件数・ユニーク投稿数・読了件数ではありません。

累計はページごとに0から始まり、再読み込み・新しいタブやウィンドウでは0に戻ります。同じページ内のタイムライン切替では保持します。ホーム以外では隠れ、同じページ内でホームへ戻ると再表示します。

位置保持にはON/OFF設定がなく、以前の版でOFFを保存していた場合も常時動作します。拡張全体を停止するには `chrome://extensions` でOFFにし、開いているXタブを再読み込みしてください。

## 権限とデータ取扱い

追加のAPI権限は要求しません。content scriptは `https://x.com/*` 上のDOMを読み書きでき、機能の対象はホームに限定しています。設定保存、Cookie・認証情報へのアクセス、通信の傍受・書換え、APIの再実行は行いません。外部へのデータ送信やテレメトリーはありません。

| データ | 保存先・上限・破棄条件 |
| --- | --- |
| 新着表示件数の累計 | ページのメモリーのみ。閉じる／再読み込みで破棄。タブ間共有・設定保存なし |
| 位置保持用ID・相対位置 | タブのメモリーに最大7件。新着処理は最大5秒。入力・画面切替・終了で破棄 |
| 概算用の計測値 | 最大500件の外側要素参照・座標・既知IDの並びと代表高さ・表示件数を最大5秒保持。終了・中断で破棄 |
| DOM計測 | 最大500投稿要素。超過時は補正を休止し、部分的な計測値で補正しない |

本文・画像・作者は保存せず、位置保持には一時的なID記録を使います。

## 確認範囲と制約

- 利用者の実際のXでは、多少のずれを許容しつつスクロールが有用だったとの報告があります。後続変更で動かなくなったとの報告を受けて当時の動作へ復元していますが、復元後の再確認は未報告です。これと、合成データによる検証は別の情報です。
- Codex環境ではXがHTTP 403となり、ログイン済みの実際のXを確認できていません。現在のXとの互換性、公式機能の実利用、通信の取得件数・頻度は未確認です。約35件という利用者報告の原因は不明で、X全体の固定上限と確認されたものではありません。

XのDOM・文言・仮想化方式が変わると動作しなくなる場合があります。ページ全体とは別の内部スクロール領域には未対応です。投稿が消えている間の空白や概算までの表示変化、ページ側が繰り返し移動する場合などのずれを防げないことがあります。継続的な保守・サポートは保証しません。
